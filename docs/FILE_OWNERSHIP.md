# File ownership

Agent 01 owns `src/app`, `src/components`, `src/pages`, `src/styles`, frontend hooks, and frontend composition. Agent 02 owns Firebase configuration, backend services, security rules, storage, functions, and backend secrets. Both agents coordinate changes to `src/types`, `src/services/contracts.ts`, `docs/FRONTEND_BACKEND_CONTRACT.md`, and `docs/AGENT_HANDOFF.md`.
