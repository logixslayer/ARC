# Feature modules

Each feature has a route definition in `src/app/routes.ts` and is rendered through the feature page composition in `src/pages/FeaturePage.tsx`. The route definition lists the page's structural sections so backend-connected feature components can replace placeholders without changing navigation.

Routes: `/app/dashboard`, `/app/brain`, `/app/tasks`, `/app/planner`, `/app/reminders`, `/app/focus`, `/app/vault`, `/app/journal`, `/app/analytics`, `/app/settings`.
